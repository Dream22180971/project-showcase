## 💡 为什么做

GitHub 主页负责告诉别人“你有哪些仓库”，作品集应该进一步解释 **这些项目为什么值得看**。

Project Showcase 增加的是视觉表达层：

- 中英文切换
- 项目筛选与搜索
- 页面和卡片动效
- 明暗视觉模式
- 数据驱动项目卡
- 响应式布局

**在线体验：** https://project-showcase.seanwalter.top

## ⚡ 5 分钟快速开始

```bash
git clone https://github.com/Dream22180971/project-showcase.git
cd project-showcase

npm install
npm run dev
```

访问 `http://localhost:3000`。

---

## 🧭 核心思路

项目信息集中管理，新增项目不需要重新改整套 UI。

```text
项目数据
   ↓
筛选 / 搜索
   ↓
卡片 / 详情页
   ↓
英文 / 中文展示
   ↓
作品集
```

---

## ✨ 核心功能

| 功能 | 说明 |
|---|---|
| 双语 UI | 英文 / 中文切换 |
| 动效 | 页面、卡片和 Hover 交互 |
| 搜索与筛选 | 按分类或关键词找项目 |
| 响应式 | 手机、平板和桌面端适配 |
| 数据驱动 | 项目信息集中在结构化数据里 |
| 主题 | 不复制内容的情况下切换视觉模式 |
